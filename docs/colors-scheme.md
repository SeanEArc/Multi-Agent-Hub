# Color Scheme

## Backgrounds and surfaces

| Role | Hex |
| --- | --- |
| Page background | `#0B0F0E` |
| Cards and panels | `#111715` |
| Search input | `#121816` |
| Live trace (log) panel, darkest | `#070A09` |
| Active nav item and selected filter | `#13281E` |

## Borders and lines

| Role | Hex |
| --- | --- |
| Dividers, card borders, progress bar track | `#1E2925` |
| Input and filter borders, dashed box | `#263330` |
| Secondary button and tag borders | `#33443F` |

## Text

| Role | Hex |
| --- | --- |
| Headings and big numbers | `#EAF2EE` |
| Body text | `#D7E3DD` |
| Secondary text (task descriptions, log messages) | `#C3D1CA` |
| Inactive nav links | `#B5C4BD` |
| Muted labels and metadata | `#8FA39A` |
| Log timestamps | `#6F857B` |

## Accent

| Role | Hex |
| --- | --- |
| Primary accent (brand mark, main button, "streaming" dot) | `#3DDC97` |
| Link hover | `#8FF2C6` |
| Text on the accent button | `#04140C` |

## Status colors

| Status | Hex |
| --- | --- |
| Running | `#3DDC97` (same as the accent) |
| Waiting | `#F2B544` |
| Error | `#FF7A6E` |
| Idle | `#8FA39A` (same as muted text) |
