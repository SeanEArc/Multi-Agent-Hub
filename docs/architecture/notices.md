# Third-party notices

## Third-party notices

**Third-party notices** (revision 4 PR 4; `scripts/notices.py`, `THIRD-PARTY-NOTICES.md`, `licenses/`): `generate` lists every package the installer ships: the backend's runtime closure walked from `multi-agent-hub-backend`'s requirements in its venv (markers and extras evaluated; dev tools left out), `package-lock.json` entries that aren't `dev`, `optional` (pdf.js's Node-only canvas) or `@types/*`, the shell's normal (non-proc-macro) dependencies from `cargo metadata --filter-platform x86_64-pc-windows-msvc`, Rust crates found by their registry source paths inside shipped `.pyd`/`.wasm` files (BetterOffice, pydantic-core, pdf.js's qcms; a lower bound, license files read from the local cargo registry or downloaded from static.crates.io into `%TEMP%\MultiAgentHub-notices`), plus Python (its runtime `LICENSE.txt` lacks the bundled OpenSSL, libffi, zlib, expat, mpdecimal and bzip2 texts, so `scripts/notices_data/python-libraries.txt` adds CPython's `Doc/license.rst` acknowledgements and bzip2's license), the PyInstaller bootloader, NSIS (`NSIS-COPYING.txt`) and Tauri's NSIS plugin. Each package's own license, notice and authors files are copied to `licenses/<section>/<name>/`; one with none uses an upstream text kept in `notices_data` (`VENDORED`), a sibling's (`BORROW`) or, when MIT with named authors, the MIT template; otherwise `generate` fails. A name shipped at several versions is one row; if their licenses differ they are joined with AND and each version's files go under `<version>/`. `generate` builds `licenses.new` and swaps it in at the end. `LICENSE_FIXES` rewrites non-SPDX metadata; `ALLOWED` (permissive plus MPL-2.0) and per-package `EXCEPTIONS` (PyInstaller's bootloader exception, NSIS's LZMA exception) gate every expression (any OR branch, every AND part). `check` (release workflow, build job, before `tauri build`; also CI's non-required **Third-party notices** job, so a dependency change shows up at PR time) compares names and licenses with the committed file, so a version-only bump just warns. The Tauri resources ship `LICENSE`, the notices and `licenses/` at the install root (not also inside the PyInstaller bundle, which only ships in the installer). `tests/core/test_notices.py` also fails CI when a new Python package isn't in the notices.
